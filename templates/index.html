Serial Number Configuration

Define how serial number prefixes map to model names and screen sizes. The program uses these rules to auto-classify every unit.

How it works

Each row defines a serial prefix (the first characters that identify the product line) and the model name it maps to. The program reads the serial, finds the matching prefix, and uses that model name on the invoice.

Size rule

86" panels are Large. Everything else (55", 65", 70", 75") is Small. The -02 suffix is determined automatically from the year character in the serial (L = 2021+).

Serial Prefix Rules
Serial Prefix Pos Model Name (–NA-R appended automatically) Size" -02 rule

-02 Rules explained

Year char (pos 5 or 6) — Reads the year letter from the serial. L or later (2021+) → adds -02.
Always -02 — Every unit with this prefix gets the -02 suffix regardless of year.
Never -02 — This product line never had a -02 revision.
